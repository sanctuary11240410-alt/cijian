# 词间 0.5 · 每日学习版

这是 Windows 本地程序。双击同文件夹中的“高中单词计划.exe”打开，学习、查词和记录都可离线使用。

## 开始使用

1. 首页查看今天选定的新学、回忆与补学数量，点击“开始今天”。新词先看讲解，到期词先回忆；显示答案后按真实情况自评。
2. “已会，移出”立即生效。点错用左上角撤销或 Ctrl+Z；“上一个词”用于回看，不重复计入学习。输入框内的 Ctrl+Z 仍用于编辑文字。
3. 非输入状态下，空格或 Enter 执行学习页当前主要动作。主要按钮固定在窗口底部。
4. “词库”中可离线查词、补充语境并选择加入，也可在全部词汇中搜索、批量移出熟词。查词本身不改变记忆进度。
5. “计划”中查看每日具体条目、完成记录、延期与待安排队列，不需要晚间手工汇报。

## 每天与每周

新档案起步设置为每天 20 分钟，周一至周六新词上限 5 条，周日默认只复习与消化积压，完整周新学目标 30 条。这些是可调起点，不是论文规定的最佳词数。你原档案已有的周目标会保留。

系统先给到期回忆与补学分配时间，再按剩余周目标、可学习日期及新词上限选择新词。个人录入的词优先于系统候选。最近延迟回忆表现较弱时会保守减量，实际用时逐步校准估计。

今天开始后固定这批任务。中途添加的词保留在待学队列，不会跳走当前词卡，也不会无限增加今天的工作。主动“加练 5 分钟”单列时间，仍遵守本人设置的新词上限；没有可加练任务时会说明。时间用满而未完成的项目记录为延期。

首个使用周期可能不足一周。界面显示剩余日期的容量上限，未使用过的日期显示暂无记录；原目标仍展示，不能将之前几天当成漏学。

具体研究、估算方式和算法边界见同目录“学习安排依据.md”，也可在计划或设置里展开查看。

## 给其他人使用：TXT 清单与学习档案

“学习档案”可以创建独立档案。每个档案分别保存进度、词条、短文、撤销与备份。

“词库 → 导入不会词 TXT”支持选择文件或粘贴，一个英文词或短语一行。先预览匹配、去重和未匹配内容，再确认导入。

- 零散积累：只添加列出的词，其他词状态保持不变。这是默认选择。
- 完整排查：仅在确实完整筛过本机明示词表后选择。范围内未列出的词标为“自报已会、免推荐”，不伪造测试成绩；已有真实学习进度和独立新义保留。
- 可以声明同时覆盖本机精选扩展包。目前精选只有 16 条，不能把它当成一份完整 1200 条扩展词书。没有筛过扩展时，扩展仍是待确认候选，不会全部变成必背生词。

明确的英美拼写与官方别名可以映射。China/china、US/us 等大小写异义分别处理，含义不明确时要求先选择条目。未匹配词可保留为个人输入，缺释义时在词典页补充。相同内容和范围重复导入不会重置记忆进度；整批导入可撤销。

## 词库范围

本版合并目录有 3847 条资料，其中核心是官方 2020 修订版词表的 3000 个独立条目；精选拓展 16 条；另有 34 条本次降级的拓展资料和 797 条旧参考资料。离线词典有 770,611 条，词典收录不等于必须背诵。

本次取消了“猜词题直接考过”“只在某个选项出现”的推荐加分。退出系统推荐不删除你的已有个人学习进度，仍可自行加入。

核心范围完整，不代表每条都有人工审校的搭配例句。音标与释义已配齐，例句、搭配有缺项会保留缺省。300–400 个重点课外词及约 1200 个词形/拓展条目仍是后续内容审核目标。详见“词库审核报告.md”。

你提到的原 Word 文档尚未直接读取成功；当前资料没有冒充来自该文档。可在设置中选择本机 DOCX 导入并核对预览。

## 趣味短文

“趣味短文”根据当天学过、测过和薄弱的词生成提示词。复制到你使用的 ChatGPT，生成后粘贴回来保存。程序不调用付费 API；短文保存不自动增加单词掌握成绩。

## 数据与升级

- 默认档案在程序旁 Data 文件夹；其他档案在 Profiles/<档案标识>/Data，profiles.json 是档案目录。
- 数据采用原子写入和自动上一份备份。实际保存失败时提示跨页保留，并阻止直接关闭；可到设置导出最新内存记录。恢复备份前另存当前记录，恢复后清除旧界面草稿。
- 新版首次打开，在自己的数据不存在时，可以复制同级旧版文件夹中最近更新的记录；旧版文件保持不变，新版保留“旧版原始记录.json”。两个版本的后续记录不会自动同步。
- 导出 JSON 只导出当前档案。要带走所有人及离线词典，请复制整个程序文件夹。
- 发布 ZIP 不包含个人 Data、Profiles 或 profiles.json。解压整个压缩包再运行，不要只取一个 EXE，也不要在压缩包内直接运行。

当前电脑已有所需的 .NET 8 桌面运行时。其他电脑需 Windows 10/11 与 .NET 8 Desktop Runtime；开发用 SDK 不随程序发布。
