# 词间 0.5 开发与验收记录

2026-09-12。Windows WPF 本地程序，.NET 8；不使用网站托管或付费模型 API。

## 本轮实现

- 今天的统一学习入口：新词先学习，到期先回忆；答错后针对性补学。识义与拼写独立保存，重复提前答对不连续延长间隔。
- 所有任务共用日时间预算。按剩余可学习日期分摊周目标；个人生词优先；周日默认缓冲；根据有效用时样本和延迟回忆表现保守调整。原周目标、今日任务、实际记录和待安排队列分别展示。
- 任务开始后保持稳定。加练只追加本人同意的时间，不绕过每日新词上限。预算不足记为延期，不标为完成。
- 三个主要导航、底部固定操作、可选笔记和来源、识义不强制中文输入、一步移出与撤销、保留查询及未提交草稿、后台离线查询。
- TXT 增量与完整排查的明确范围、预览、版本核验、别名与大小写异义、已有真实进度保护、自报已会、重复导入幂等、整批撤销。
- 本地档案隔离与旧版记录复制迁移；保存失败跨页提示并阻止直接关闭；恢复前备份和草稿清理。
- 核心 3000 范围、精选 16 与参考资料分层、独立条目身份；复核不因单个猜词题或选项而自动推荐。

## 这轮自我纠正发现并修复的问题

1. 加练曾同时放宽新词上限：改为只增加时间，仍守日上限，并加入回归场景。
2. 词典按拼写取第一个词条会误改独立义项：改为按稳定条目打开；普通搜索遇到歧义先选择。
3. 恢复备份后旧草稿可能覆盖恢复后的笔记：恢复时清除旧界面会话，并验证重新打开显示备份笔记。
4. 保存失败可能被成功通知和导航遮盖：增加持续错误状态，以真实文件锁测试失败和恢复。
5. 新核心词库中的大小写异义会让旧 DOCX 字典索引报错：按准确拼写分组并保留各自身份和范围。

测试证明程序行为符合上述规则，不证明它已经提高长期记忆或高考成绩。每日数量与间隔参数仍需依据后续真实使用调整；没有伪称个人遗忘曲线已拟合。300–400/1200 扩展内容尚未完成，当前范围见词库审核报告。
