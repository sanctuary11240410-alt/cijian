# 开发与内容生成说明

日常编译直接使用 `src/WordCoach.App/Assets/` 内已生成的 JSON，无需重新下载 PDF、教材或词典 CSV。离线词典数据库需从 Release 复制或自行构建，见根目录 README。

## .NET 项目

`WordCoach.Core` 是 net8.0 类库，`WordCoach.App` 是 net8.0-windows WPF 程序。测试使用独立控制台入口，不依赖 xUnit 等测试框架。请在仓库根目录执行 README 中的测试命令。

`UiChecks` 是旧版界面检查，保留作历史参考；当前界面使用 `UiV05`。测试、构建产物与实际学习档案不提交。

## Python 内容工具

- `build_dictionary.py`：Python 3.11+ 标准库，将指定 ECDICT CSV 转为 SQLite，输入和输出通过命令行传入。
- `build_vocabulary.py`：历史参考目录生成器；默认读取仓库同级 `frequency-source/english.txt`。历史频率字段不作为当前默认推荐的充分依据。
- `build_core_vocabulary.py`：需要 `pypdf`、仓库同级 `corpus-research/curriculum-2020.pdf`、已生成参考 JSON 和离线词典。它重新生成核心 JSON 与范围元数据。
- `build_extension_vocabulary.py`、`audit_extension_evidence.py`：历史内容整理与原卷出现核验脚本，依赖仓库同级 `corpus-research/` 研究材料；具体文件名以脚本常量为准。原卷出现不能直接证明某词值得背诵。

原始教材、试卷 PDF、研究目录和个人 DOCX 不随源码发布。需要重新生成内容时，请自行按明确来源准备输入、核验许可，并先在副本上运行；否则应直接使用已提交的版本化 JSON。不要把内容生成脚本全部运行当成常规编译步骤。

## 发布约定

源码不包含 dictionary.db，完整程序包包含它与对应 MIT 许可。打包始终排除 Data、Profiles、profiles.json、备份、测试数据与 PDB。发布 ZIP 必须包含 EXE、DLL、运行配置和 Assets，而非单独 EXE。

升级前让使用者导出当前档案，解压新版到独立目录并按使用说明迁移；不要覆盖或删除唯一的数据副本。
